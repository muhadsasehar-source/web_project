# Numa - Skincare E-Commerce Website

## Project Overview
Numa Mongo is a skincare e-commerce website developed using PHP, MongoDB, HTML, CSS, and JavaScript.
The website allows users to browse skincare products, add items to the cart, and complete purchases through a simple checkout process.

## Features

- Home page with featured products
- About Us page
- Contact page
- Product listing page
- Product sets collection
- Shopping cart functionality
- Checkout and purchase system
- MongoDB database integration
- Responsive user interface

## Technologies Used

- PHP
- MongoDB
- HTML5
- CSS3
- JavaScript
- XAMPP (Apache Server)
